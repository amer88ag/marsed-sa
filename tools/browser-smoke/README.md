# فحوص المتصفح المحلية (Chrome حقيقي)

أدوات تطوير محلية فقط. **لا تعمل في GitHub Actions، ولا تتصل بأي خدمة خارجية حية.** كل البيانات فيها اصطناعية أو من ملفات المستودع. نجاحها يثبت سلوك الصفحات والمتصفح في بيئة اختبار، ولا يثبت شيئاً عن توفر الخدمات الخارجية أو صحة بياناتها.

## 1. `smoke.js` — تشغيل الصفحات في بيئة معترَضة

يفتح الصفحات الست (index، seasons، elevation، satellite، satellite/coverage، admin) في Chrome بعرض 390px. ويعترض **كل** طلب شبكة عبر `context.route` في Playwright، فلا يخرج أي طلب إلى الإنترنت:

| الطلب | ما يحدث |
|---|---|
| `http://local.test/*` | يُقدَّم من ملفات المستودع |
| `unpkg.com` (Leaflet) | يُقدَّم من نسخة محلية مثبتة بـ npm |
| `api.open-meteo.com/v1/elevation` | رد اصطناعي `{elevation:[2210]}` |
| `*.open-meteo.com` (توقع، أرشيف، دفعات) | رد اصطناعي ثابت الشكل |
| `router.project-osrm.org` | مسار اصطناعي |
| `gibs.earthdata.nasa.gov/.../wmts.cgi` | DescribeDomains اصطناعي (`2026-01-01/2026-11-23/P1D`) |
| بلاطات GIBS وبلاطات OSM وأي طلب آخر | **محجوبة** (`route.abort`) |

**ما يثبته:** الصفحات تُحمَّل وتعمل وتعرض الحالات دون أخطاء JavaScript ودون تجاوز أفقي عند 390px، في هذه البيئة.

**ما لا يثبته:** اتصال أي خدمة خارجية حية، أو صحة بياناتها. ولأن البلاطات محجوبة، يُظهر فحص التغطية «فشل/مهلة 76 من 76»، وهذا يثبت فقط أن الصفحة تعرض الفشل بأمانة.

## 2. `coverage-real-cors.js` + `cors-servers.py` — سلوك CORS داخل Chrome

اختبار **حقيقي لسلوك CORS في Chrome بين أصلين مختلفين**، على خادمين محليين دون أي اعتراض من Playwright:
- الموقع على `127.0.0.1:8801`، من ملفات المستودع.
- البلاطات على `127.0.0.1:8802`.

**خادم البلاطات ومحتوى DescribeDomains اصطناعيان ومحليان.** أثناء التقديم فقط يُوجَّه عنوان GIBS في `nasa-gibs.js` إلى الخادم المحلي، دون تعديل الملف في المستودع. لكل طبقة سيناريو معروف (`tiles/manifest.json`):
- نسيج مع ترويسة CORS.
- نصف أسود مع CORS.
- أسود مع CORS.
- نسيج بلا ترويسة CORS.

**ما يثبته:** أن Chrome يطبق CORS فعلياً، وأن الكود يصنّف البلاطة صالحة أو جزئية أو فارغة، أو «حُمّلت دون تحقق» عند غياب CORS.

**ما لا يثبته:** أن خوادم NASA GIBS الحقيقية ترسل ترويسات CORS، أو أن صورها الحالية صالحة. هذا يحتاج اختباراً حياً منفصلاً من جهاز متصل.

## 3. `cors-probe.js`

يوثق أن `route.fulfill` في Playwright **يتجاوز CORS**، ولذلك لا يصلح لاختبار CORS. هذا سبب فصل الاختبار 2 عن الاختبار 1. المضيف `tiles.example.org` فيه عنوان وهمي تُعترض طلباته.

## 4. خارج هذه الأدوات

لقطة نطاقات GIBS في `test/fixtures/gibs-live-domains-2026-11-25.json` **بيانات ثابتة** التُقطت مرة واحدة، وليست اختباراً حياً.

## التشغيل

```
npm i leaflet@1.9.4 playwright
```

```
node smoke.js > chrome-smoke.log
```

```
node make-tiles.js && (python3 cors-servers.py ../.. & sleep 1; node coverage-real-cors.js > coverage-real-cors.log; kill %1)
```
