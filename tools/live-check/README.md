# الفحص الحي للمصادر — يُشغَّل يدوياً من جهاز متصل بالإنترنت

هذه الأداة تغلق فجوة «التحقق الحي من Open-Meteo وCHIRPS» التي تعذر إغلاقها من بيئة التطوير. **لا تُشغَّل في GitHub Actions**، ولا تكتب في المستودع، ولا تحتاج مفاتيح أو تبعيات.

## التشغيل

يحتاج Node.js 18 أو أحدث. يُشغَّل من جذر المستودع:

```
node tools/live-check/live-check.js
```

ولحفظ النتيجة بصيغة JSON أيضاً، في ملف `live-check.json`:

```
node tools/live-check/live-check.js --json
```

## ما يفحصه

تستخدم الأداة دوال بناء الروابط نفسها في التطبيق، وسياسة الوحدات نفسها، ومنطق التواريخ نفسه. فهي تختبر الافتراضات التي بُني عليها الكود فعلاً:

| الرمز | الفحص |
|---|---|
| OM1 | توقع Open-Meteo: الوحدات المعلنة لكل حقل مطلوب، و`interval = 900`، و`utc_offset_seconds = 10800`، والمنطقة الزمنية، وحداثة القيمة الحالية |
| OM2 | أرشيف Open-Meteo: الوحدات، والأيام الأخيرة الناقصة (تأخر الأرشيف، معلومة لا خطأ) |
| OM3 | الارتفاع: معقولية القيمة للرياض (400–900 م) |
| OM4 | دفعة نقاط الطريق: تغطية نافذة 48 ساعة فعلاً |
| CH-sat / CH-rnl | CHIRPS v3 النهائي: هل نُشر ملف آخر يوم تتوقعه سياسة «الأسبوع الثالث + هامش 7 أيام»؟ |
| GB-* | NASA GIBS لأربع طبقات: نطاق التواريخ، وسقف UTC، ونوع البلاطة، وترويسة CORS الحقيقية |
| OS1 | OSRM: معقولية مسار الرياض ← جدة |

## قراءة النتيجة

| الحالة | المعنى |
|---|---|
| `VERIFIED` | استجابت الخدمة، وكل الافتراضات صحيحة |
| `FAILED_VERIFICATION` | استجابت الخدمة لكن افتراضاً لم يتحقق: **نتيجة تحتاج مراجعة**، وتُذكر تحتها بسطر يبدأ بـ `!` |
| `SERVICE_ERROR` | استجابت بخطأ HTTP أو بمحتوى غير صالح |
| `UNREACHABLE` | لا استجابة من هذا الجهاز (شبكة، DNS، وكيل، مهلة). **لا تعني نجاح الخدمة ولا فشلها** |

رمز الخروج: `0` كل الفحوص متحققة · `1` توجد نتائج تحتاج مراجعة · `2` غير حاسم (بعض المصادر غير قابلة للوصول).

## حدود الأداة

- لا تحلل بكسلات صور الأقمار. ذلك يحتاج المتصفح، عبر `tools/browser-smoke` على نسخة Preview.
- لا تتحقق من الصحة العلمية للقيم، بل من شكلها ووحداتها وتوقيتها ومعقوليتها فقط.
- نتيجتها لقطة لحظة التشغيل، لا مراقبة مستمرة.
