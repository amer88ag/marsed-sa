# رادار الطيران العالمي

## ما تم تنفيذه
- صفحة مستقلة على المسار `/air/`.
- خريطة تفاعلية لحركة الطائرات المرصودة عبر OpenSky Network.
- اختيار نطاق الرياض وجدة والدمام ومكة/الطائف وأبها أو حدود الخريطة.
- تفاصيل الطائرة: ICAO24، نداء الرحلة، بلد المصدر، الموقع، الارتفاع البارومتري والهندسي، السرعة، الاتجاه، معدل الصعود/الهبوط، حالة الأرض/الجو، ووقت آخر اتصال.
- بحث وتصفية الطائرات وتحديد طائرة على الخريطة.
- تحديد موقع المستخدم اختيارياً.
- عرض وقت آخر تحديث ومصدر البيانات.
- إضافة مدخل من الصفحة الرئيسية وسجل الخدمات.

## حدود المصدر
OpenSky REST API يعرض state vectors المستلمة من ADS-B/Mode S، وليس جدول رحلات تجارياً. لا يضمن ظهور كل الطائرات. لا يوفر بمفرده جداول الوصول والمغادرة، التأخير والإلغاء، البوابات أو الصالات. لذلك لا تعرض الصفحة هذه الحقول كتخمينات.
الطلب المجهول محدود بحصص يومية، وتختلف كلفة الطلب حسب مساحة النطاق. يتم التحديث تلقائياً كل خمس دقائق ما دامت الصفحة ظاهرة، مع زر للتحديث اليدوي. وقد تتوقف الطلبات عند استنفاد الحصة. لا تستخدم الصفحة لأغراض السلامة أو الملاحة الجوية.

## بوابة الترخيص قبل النشر العام — مانع إطلاق
شروط OpenSky الرسمية الحالية تقصر استخدام البيانات على البحث والتعليم غير الربحي، وتشترط اتفاقاً/ترخيصاً كتابياً لأي استخدام تشغيلي لواجهة REST داخل منتج أو خدمة حية، حتى للجهات غير الربحية. لذلك تبقى هذه الصفحة في حالة `research` ولا يجوز اعتبارها جاهزة للنشر العام أو التشغيل المستمر قبل الحصول على موافقة مكتوبة من OpenSky أو استبدال المصدر بموفر يسمح صراحة بالاستخدام التشغيلي والعرض العام.
المراجع الرسمية:
- https://opensky-network.org/about/terms-of-use
- https://opensky-network.org/about/faq

## ما يتطلب استكمالاً منفصلاً
لوحة الرحلات التجارية الكاملة (الوصول والمغادرة المجدولة والفعلية، حالة التأخير والإلغاء، البوابات والصالات، وشركات الطيران والمسار الكامل) تحتاج موصل بيانات مطارات/رحلات مرخصاً يغطي المطارات المطلوبة. لم يتم ربط مزود مدفوع أو مفاتيح API. كما أن سجل المسار التاريخي يتطلب مزوداً أو أرشيفاً تاريخياً؛ لا يستنتج من لقطة الحالة الحالية.
