# التصور الفني المبدئي

## مبادئ التصميم
- البدء ببنية بسيطة ومنخفضة التكلفة، وتجنب الخدمات المدفوعة الإلزامية.
- فصل جلب البيانات ومعالجتها عن واجهة الخريطة.
- حفظ بيانات المصدر الخام أو روابطها وفق شروط الترخيص، وعدم نسخها تلقائياً قبل التحقق.
- جعل كل طبقة مرتبطة ببيانات وصفية واضحة.

## المكونات المقترحة

1. **واجهة الويب:** تطبيق خريطة تفاعلية متجاوب باللغة العربية.
2. **كتالوج البيانات:** تعريف المصادر والمنتجات والإصدارات والتراخيص والدقة والتغطية.
3. **خط معالجة:** تنزيل العينات، التحقق من الملفات، توحيد الوحدات والإحداثيات، وإنتاج طبقات قابلة للعرض.
4. **التخزين:** ملفات جغرافية أو راستر حسب الحاجة، مع تجنب قاعدة بيانات مكانية مدفوعة في مرحلة إثبات المفهوم.
5. **الاختبارات:** فحوص المخطط والوحدات والمدى الزمني والإحداثيات والقيم الناقصة.

## قرارات مؤجلة

- اختيار إطار الواجهة ومكتبة الخرائط بعد إثبات مصدر البيانات.
- اختيار PostGIS فقط عند ظهور حاجة فعلية للاستعلامات المكانية أو إدارة بيانات متعددة المستخدمين.
- تحديد الاستضافة بعد اختبار حجم البيانات وتكلفة النقل والتخزين ضمن الميزانية المجانية.
- عدم وضع مفاتيح API أو أسرار في المستودع أو في كود المتصفح.
