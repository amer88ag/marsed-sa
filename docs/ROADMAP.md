# خارطة طريق مرصد السعودية

## المرحلة 0 — التأسيس والحوكمة
- [x] إنشاء المستودع العام.
- [x] توثيق النطاق الوطني والإتاحة العامة والميزانية المجانية.
- [x] إنشاء سجل أولي لمصادر البيانات والتراخيص.
- [ ] مراجعة شروط CHIRPS وNASA GPM للمنتجات المحددة وتوثيق القرار.
- [ ] تثبيت سياسة الخصوصية والأمان وإدارة المفاتيح إن لزم.

## المرحلة 1 — إثبات صلاحية البيانات
- [ ] تنزيل عينات صغيرة من مصدرين مرشحين.
- [ ] اختبار تغطية السعودية وعسير وحدود البيانات.
- [ ] توحيد الوحدات والتوقيت والإحداثيات.
- [ ] قياس القيم المفقودة والتأخر الزمني.
- [ ] توثيق القيود وعدم اليقين.

**بوابة القبول:** لا يبدأ بناء واجهة تعرض بيانات فعلية قبل نجاح اختبارات العينة وتوثيق الترخيص.

## المرحلة 2 — نسخة الخريطة الأولى
- [ ] خريطة المملكة وحدود المناطق الإدارية من مصدر مرخص.
- [ ] طبقة أمطار تاريخية مع اختيار التاريخ والفترة.
- [ ] وسيلة إيضاح ووحدات ومصدر وتاريخ تحديث ظاهر.
- [ ] تصميم متجاوب للجوال والحاسوب وإمكانية الوصول.

## المرحلة 3 — التحليل والمقارنة
- [ ] مقارنة منتجات الأمطار مع بيان اختلاف الدقة والمنهجية.
- [ ] ملخصات حسب المنطقة والمحافظة عند دعم البيانات لذلك.
- [ ] تصدير النتائج فقط إذا سمحت التراخيص.

## المرحلة 4 — التوسع
- [ ] رطوبة التربة.
- [ ] الغطاء النباتي ومؤشر NDVI.
- [ ] طبقات المياه والسيول عند توفر بيانات موثوقة ومسموح باستخدامها.
- [ ] تنبيهات تجريبية مع بيان أنها ليست بديلاً عن التحذيرات الرسمية.

## ضوابط الإصدار
- لا ادعاء بتوقع السيول دون نموذج مُختبر ومُتحقق منه.
- لا تسمية تقديرات الأقمار الصناعية قياسات أرضية.
- كل طبقة تحمل المصدر والتاريخ والدقة والوحدة والترخيص.
- الخدمات الأساسية يجب أن تبقى ضمن خطة مجانية أو مجانية الاستضافة ذات حدود معلنة.
