## ضوابط الإصدار
- لا ادعاء بتوقع السيول دون نموذج مُختبر ومُتحقق منه.
- لا تسمية تقديرات الأقمار الصناعية قياسات أرضية.
- كل طبقة تحمل المصدر والتاريخ والدقة والوحدة والترخيص ونوع المنتج.
- الخدمات الأساسية يجب أن تبقى ضمن خطة مجانية أو مجانية الاستضافة ذات حدود معلنة.
- لا توضع بيانات الدخول أو مفاتيح API في كود المتصفح أو ملفات المستودع.
