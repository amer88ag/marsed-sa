# حالة التنفيذ — مرصد السعودية

آخر تحديث: 2026-11-21

## ما أصبح موجوداً في المستودع

- مستودع عام باسم `amer88ag/marsed-sa` والفرع الأساسي `main`.
- واجهة عربية RTL في `index.html`.
- خريطة تفاعلية تعتمد Leaflet وOpenStreetMap.
- اختيار 13 مدينة سعودية وتحريك المؤشر إلى إحداثياتها.
- جلب مؤشرات طقس نموذجية من Open-Meteo: الحرارة والرطوبة والهطول والرياح.
- مخطط يومي للأمطار يعرض الأيام السابقة واللاحقة المتاحة من واجهة الطقس.
- كتالوج أولي للمصادر المرشحة وروابطها الرسمية.
- توضيح ظاهر أن قيم Open-Meteo ناتج نموذج وليست قياسات محطات رسمية.

## ما لم يكتمل — لا تعتبره جاهزاً للإنتاج

1. لا توجد حتى الآن طبقة حدود إدارية موثقة للمناطق والمحافظات.
2. لا توجد طبقة راستر تاريخية للأمطار من CHIRPS أو NASA IMERG موصولة بالواجهة.
3. لا يوجد تحقق ميداني أو مقارنة مرجعية بمحطات NCM.
4. لا يوجد اعتماد ترخيص نهائي لإعادة نشر أو إعادة استضافة منتجات CHIRPS/IMERG.
5. لا يوجد تكامل مع API المركز الوطني للأرصاد؛ يلزم اعتماد رسمي ومراجعة الشروط.
6. لا توجد بيانات رطوبة تربة أو NDVI أو مخزون مياه أو سيول.
7. لا توجد تنبيهات تشغيلية، ولا يجوز استخدام اللوحة الحالية للإنذار أو السلامة.
8. لم يتم بعد اختبار الأداء على أجهزة متعددة أو مراقبة توفر الخدمات الخارجية.

## قرارات تقنية

- تبقى الواجهة خفيفة وبدون قاعدة بيانات في مرحلة إثبات المفهوم.
- لا توضع مفاتيح API في المتصفح أو المستودع.
- لا تُعرض بيانات النماذج بوصفها رصداً رسمياً.
- لا تُفعّل طبقة بيانات جديدة قبل توثيق مصدرها وترخيصها ووحداتها ودقتها وتاريخ تحديثها.
- الخدمات الخارجية (Leaflet وOpenStreetMap tiles وOpen-Meteo) تعتمد على توفر مزوديها وسياساتهم وحدود الاستخدام.

## بوابة الإصدار

لا توصف النسخة بأنها «مرصد وطني مكتمل» إلا بعد اجتياز اختبارات البيانات الجغرافية، والترخيص، والتحقق من الجودة، والتغطية الوطنية، وإتاحة الخدمة ومراقبتها.
