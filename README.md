# مرصد السعودية للمناخ والمياه

منصة وطنية عامة لمتابعة وتحليل بيانات المناخ والمياه والغطاء الأرضي في المملكة العربية السعودية، مع التركيز على البيانات المفتوحة والمصادر المجانية.

## قرارات المشروع المعتمدة

- **النطاق:** وطني — جميع مناطق المملكة العربية السعودية.
- **الإتاحة:** عامة (Public).
- **الميزانية:** مجانية قدر الإمكان، دون اعتماد على خدمات مدفوعة لتشغيل الوظائف الأساسية.
- **اللغة الأساسية:** العربية، مع قابلية إضافة الإنجليزية.
- **المبدأ:** إظهار مصدر كل طبقة وتاريخ تحديثها ودقتها ووحداتها وشروط استخدامها.

## أهداف النسخة الأولى

1. خريطة تفاعلية للمملكة.
2. عرض بيانات الأمطار التاريخية والحديثة بحسب التغطية المتاحة.
3. مقارنة أكثر من مصدر بيانات مع توضيح اختلاف الدقة والتأخر الزمني.
4. عرض مؤشرات رطوبة التربة والغطاء النباتي عند التحقق من المصادر والتراخيص.
5. صفحات وصفية للبيانات والمنهجية والتنبيهات وحدود الدقة.
6. تصميم قابل للتوسع لإضافة بيانات المياه والسيول لاحقاً.

## مبادئ البيانات والتراخيص

- لا تُعرض أي مجموعة بيانات على أنها مجانية أو مفتوحة الترخيص قبل مراجعة شروط المصدر الرسمية.
- لا نعيد استضافة البيانات أو نوزعها قبل التحقق من شروط النسخ وإعادة النشر والإسناد.
- تُسجل لكل مصدر: الجهة المالكة، الرابط الرسمي، الترخيص، الدقة المكانية والزمنية، التغطية، التأخر، صيغة البيانات، وتاريخ آخر تحقق.
- تُفصل البيانات المرصودة أو المقدرة عن التوقعات والنماذج، ولا تُعرض التقديرات على أنها قياسات أرضية مباشرة.

## حالة التطوير

المستودع في مرحلة إثبات المفهوم والبحث، وليس خدمة تشغيلية أو مصدراً معتمداً للإنذار. توجد عينة بحثية فعلية من CHIRPS SAT وRNL لثلاثة أيام و13 موقعاً نقطياً، واجتازت اختبارات CI، لكنها لا تمثل قياسات محطات ولا متوسطات المدن ولا اعتماداً للإنتاج. لم يتم اعتماد مصدر بيانات للإنتاج أو إطلاق خدمة تشغيلية. ستوثق نتائج فحص المصادر والتراخيص في docs/DATA_SOURCES.md.
